# Uttal — スウェーデン語の発音練習

お手本を聞いて、まねして言う。ブラウザの音声認識が「その語に聞こえたか」で ○ × が出ます。

**https://fika-driven.github.io/uttal/**

- スマートフォンでも使えます（iPhone / Android の Safari・Chrome）
- 記録はその端末の中だけに残ります。サーバーには何も保存しません
- 収録：場面別の語 520 ／ フレーズ 126

## 中身について

このページは個人的なスウェーデン語学習アプリから、**一般的な語彙だけ**を自動抽出して生成したものです。
生成時に個人情報が含まれていないことを機械的に検査しており、1件でも見つかれば生成が中断されます。

`index.html` は生成物です。直接編集せず、元のアプリ側を直してから作り直してください。
